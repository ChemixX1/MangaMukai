# Fuentes locales

Estas fuentes se cargan en el frontend actual. Cada familia conserva su licencia
para que el proyecto pueda distribuir sus archivos respetando las condiciones
del autor.

| Familia | Uso |
| --- | --- |
| Montserrat | Texto y controles de todo el sitio |
| MuseoModerno | Reloj de la ficha del manga |
| Anta | Etiquetas y detalles de la interfaz |
| Archivo Black | Encabezados y controles de la ficha |
| Poppins | Comentarios y boletín del pie |
| Cinzel | Firma del perfil |
| Dela Gothic One | Mercado de monedas |
| Sora | Mercado de monedas |
| Rajdhani | Mercado de monedas |

`manga-detail.css` carga las seis primeras variantes de fuentes compartidas,
incluida la cursiva de Montserrat. Cinzel y las fuentes del mercado se cargan
desde los estilos de sus páginas.

Black Ops One, Shojumaru y Yuji Syuku se retiraron porque ningún apartado actual
las utiliza. Al retirar una familia se retira también su licencia local.
